# CS50 coursework and exercises

Smaller projects and exercises from Dartmouth CS50, Spring 2025.

| Folder | Contents |
| --- | --- |
| `lab1-mith-r` | Shell scripts for summarizing vaccination data |
| `lab2-mith-r` | C programs for wind chill, word processing, and histograms |
| `activity7-aura` | COVID-data programming activity |
| `activity23-gitflow-wecooked` | Collaborative Git branching exercise |
| `repo1` | Introductory Git practice |
| `memorygames` | C string and memory exercises |
| `exercises` | Madlib, line-reading, and introductory exercises |
| `environment` | Original course setup files |

## History

The original repositories were combined without squashing or rewriting their
commits. Their authors, timestamps, and commit IDs are preserved. Original
branches are retained under `archive/<source-repository>/`. New commits record
the restoration and previously uncommitted files; they are dated when restored.

These exercises were developed on Dartmouth's Linux servers. References to
`/thayerfs` and the `shared` symlink require the original course environment;
external course data is not bundled here. Generated executables, editor caches,
and swap files are excluded from the restored working tree.

Larger projects are available separately:
[Nuggets](https://github.com/mith-r/nuggets),
[Tiny Search Engine](https://github.com/mith-r/tiny-search-engine), and
[C data structures](https://github.com/mith-r/c-data-structures).
